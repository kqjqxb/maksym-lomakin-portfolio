05My take on AI

Fast is useless if you can't trust it

What I've learned after using AI agents on production code every day, and write about openly.

Where it shines

Leverage on the boring 70%

  • Scaffolding, refactors and parallel bug fixes
  • Audits I'd never have time for: QA risk, retention, trade-offs
  • Up-to-date docs and pixel-accurate UI through MCP
Where it bites

Confident, plausible and wrong

  • Native edge cases: background limits, lifecycle, signing
  • Race conditions it happily introduces
  • Drift from the codebase's own conventions
My rules

AI drafts, I own it

  • Every diff gets reviewed and tested on a real device
  • Agents are versioned files with narrow jobs
  • Structured output over free text, and ask instead of guess
